SmartRecruit
智能简历推荐系统

RAG LangGraph Python Milvus Elasticsearch

项目概述

SmartRecruit 是一套基于 RAG（检索增强生成）全链路的智能招聘推荐系统， 旨在解决传统招聘平台中"语义鸿沟"、"格式混乱"和"推荐不可解释"三大核心痛点。

系统支持 PDF、图片等多格式简历解析，结合 Milvus 向量数据库与 Elasticsearch 全文检索的混合检索策略，配合大模型生成可解释的推荐理由， 大幅提升人岗匹配的准确率与用户体验。

系统架构

简历解析

PyMuPDF + PaddleOCR 多格式解析，LayoutParser 版面分析，信息抽取准确率达 92%

混合检索

Milvus 向量召回 + Elasticsearch BM25 精排，Multi-Query Retriever 拓展查询面

智能推荐

LangGraph 状态机编排 LLM 调用，生成结构化推荐报告与可解释匹配理由

技术栈

大模型

Qwen-7B-Chat（本地部署，4×A5000 量化推理）

向量检索

Milvus 2.x，HNSW 索引，Top-K 语义召回

全文检索

Elasticsearch 8.x，BM25 评分，自定义 boosting 策略

流程编排

LangChain + LangGraph，状态机管理多步推理流程

后端服务

FastAPI + Uvicorn，异步并发，Pydantic 数据校验

前端界面

Streamlit 快速原型，支持简历上传、实时推荐、报告导出

项目亮点

  • 混合检索策略：向量语义召回 + 关键词精排，MRR@10 提升 23%，解决单一检索的语义漂移问题
  • 可解释推荐：LLM 生成自然语言匹配理由，而非黑盒打分，显著提升用户信任度
  • 多格式解析：PDF/图片/Word 全覆盖，LayoutParser 版面复原，信息抽取准确率 92%+
  • LangGraph 状态机：将推荐流程建模为可控状态转移，支持条件分支、回滚与人工审核介入
  • 容器化部署：Docker + Docker Compose 一键部署全部依赖服务，降低环境配置成本
