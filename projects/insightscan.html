InsightScan
扫智通 Agent

Agent Ollama LangChain RAG ChromaDB

项目概述

InsightScan（扫智通）是一套面向扫地机器人的具身智能服务中枢， 基于 ReAct + Agentic RAG 架构，打通售前咨询、售后故障诊断与个性化设备运行报告三大场景， 实现真正的"售前售后一体化"智能客服体验。

系统本地部署 Qwen3 / DeepSeek-R1 开源大模型（Ollama 推理）， 无需联网即可运行，兼顾数据安全与响应速度，平均响应时间 < 1.2s。

核心功能

售前咨询

理解用户需求，对比推荐合适的扫地机器人型号，解答功能、价格、适配场景等问题

售后故障诊断

多轮对话引导用户描述故障现象，结合知识库精准定位问题并给出 step-by-step 解决方案

个性化运行报告

主动生成设备使用周报/月报，涵盖清扫面积、耗时、耗材状态，并给出个性化建议

系统架构

用户输入

Web UI（Gradio）接收自然语言提问，支持多轮对话上下文管理

Agentic RAG

ReAct 框架决策检索策略，ChromaDB 向量库 + bge-m3 多语言 Embedding

LLM 生成

Qwen3 / DeepSeek-R1 本地推理，生成准确、可解释的回答

技术栈

本地大模型

Qwen3、DeepSeek-R1，Ollama 本地推理框架

Agent 框架

LangChain 0.3 + ReAct，工具调用与多步推理

向量数据库

ChromaDB，bge-m3 Embedding，支持中英双语检索

前端界面

Gradio 快速构建 Web UI，支持对话历史、文件上传

知识库

10 类问题覆盖售前/售后，PDF 文档解析 + 语义切分

部署环境

Conda 环境管理，本地离线运行，无需云端 API

项目亮点

  • Agentic RAG：ReAct 框架让 Agent 自主决定"是否检索、检索什么、如何整合"，而非固定流程
  • 本地化部署：完全离线运行，用户数据不出本地，隐私安全有保障
  • 多轮对话：维护对话历史上下文，支持追问、澄清、确认等自然交互模式
  • 主动服务：不仅被动应答，还能主动生成设备运行报告，提供个性化建议
  • 易扩展：知识库采用标准化格式，新增产品型号只需补充文档，无需改代码
