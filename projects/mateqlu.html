MateQlu
搭子小程序

Spring Boot uni-app MySQL 微信小程序 MyBatis

项目概述

MateQlu（齐工大搭子）是一款面向齐鲁工业大学学生的微信小程序， 致力于解决校园内"找搭子难"的痛点——无论是一起学习、运动、吃饭还是做项目， 都能快速找到志同道合的校园伙伴。

后端采用 Spring Boot + MyBatis 架构，部署于阿里云服务器（ECS）， 数据库使用 MySQL，API 接口通过域名 zmdxc.com 对外提供访问。 前端基于 uni-app 开发，一套代码同时支持微信小程序与 H5。

核心功能

任务发布

支持发布各类搭子任务（学习、运动、美食、项目），设置时间、地点、人数限制

智能匹配

基于兴趣标签、时间安排、地理位置多维度匹配，提高搭子质量和成功率

即时聊天

内置 WebSocket 实时通讯，匹配成功后可直接在应用内沟通详情

系统架构

微信小程序

uni-app 前端，微信授权登录，流畅的卡片式交互体验

Spring Boot 后端

RESTful API，MyBatis ORM，JWT 身份认证，全局异常处理

MySQL + 阿里云

阿里云 ECS 部署，MySQL 持久化存储，OSS 对象存储图片

技术栈

后端框架

Spring Boot 3.x，MyBatis-Plus，Spring Security + JWT

数据库

MySQL 8.0，Redis 缓存用户会话，索引优化查询性能

前端框架

uni-app（Vue 3 语法），微信小程序 SDK，uView UI 组件库

部署运维

阿里云 ECS（CentOS），Nginx 反向代理，域名备案与 SSL 证书

即时通讯

WebSocket STOMP，好友匹配后自动建立会话通道

第三方登录

微信 OAuth2.0 授权登录，openid 绑定本地用户体系

项目亮点

  • 全栈独立开发：从需求分析、数据库设计、后端接口到前端页面，全程独立完成后端核心模块
  • 真实生产部署：已完成阿里云上线部署，域名备案、HTTPS 配置、服务器运维全流程实战
  • 微信生态深度集成：微信登录、微信支付（规划中）、订阅消息通知，熟悉微信小程序开发规范
  • 数据库设计能力：用户表、任务表、匹配关系表、会话表，合理设计索引与外键约束
  • 持续迭代中：项目仍在活跃开发，计划加入推荐算法优化与社区动态功能
