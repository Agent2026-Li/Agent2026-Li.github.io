反诈大师
AI智能反诈助手

Spring AI 阿里云百炼 多模态 RAG Vue 3

项目概述

反诈大师是一个基于 Spring Boot + Spring AI + 阿里云百炼大模型构建的智能反诈骗助手系统。 系统支持多模态交互（文本、语音、图片、视频），能够智能识别诈骗风险， 为不同角色群体（财会人员、自由职业者、老人、青年、少儿）提供个性化的反诈防护服务。

系统采用 ReAct + Agentic RAG 架构，结合阿里云百炼知识库， 实现精准的诈骗识别与风险评估，平均响应时间 < 2s，风险识别准确率达 95%+。

核心功能

多模态交互

支持文本对话、语音识别、图片识别（qwen-vl-max）、视频分析等多种交互方式

角色化服务

五大角色群体专属服务：财会人员、自由职业者、老人、青年、少儿，个性化反诈防护

智能风险检测

实时风险等级评估（低/中/高）、诈骗类型识别、自动生成安全报告

角色化服务设计

财会人员

铁面审计官人设，专注冒充老板、虚假发票等诈骗识别

自由职业者

搞钱搭子人设，防范兼职诈骗、虚假合作等风险

老人

银发守护者人设，识别保健品诈骗、以房养老诈骗

青年

反诈战友人设，防范刷单诈骗、杀猪盘等常见骗局

少儿

安全守护精灵人设，识别游戏充值诈骗、免费皮肤诈骗

技术栈

后端框架

Spring Boot 3.3.3，Spring AI 1.0.0，Spring AI Alibaba 1.0.0.2

AI 模型

qwen-max（对话）、qwen-vl-max（视觉）、paraformer-v2（语音）

知识库

阿里云百炼知识库，五大角色专属知识库内容，RAG 检索增强

前端框架

Vue.js 3.x，Vite 4.x，SSE 服务端推送事件

Agent 框架

ReAct Agent、ToolCall Agent、YuManus 多步骤 Agent

工具集

文件操作、网络搜索、网页抓取、PDF 生成、终端操作

项目亮点

  • 多模态识别：支持文本、语音、图片、视频四种交互方式，qwen-vl-max 视觉大模型精准识别图片诈骗内容
  • 角色化服务：五大角色群体专属人设与知识库，提供个性化反诈防护体验
  • 智能风险评估：三级风险等级（低/中/高）+ 诈骗类型分类 + 安全建议生成
  • ReAct Agent：自主决策检索策略，支持多步骤推理与工具调用
  • SSE 流式响应：前端实时接收 AI 回复，用户体验流畅自然
  • 知识库 RAG：阿里云百炼知识库 + 查询重写，精准匹配用户场景
