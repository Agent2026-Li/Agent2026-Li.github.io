基于 SpringBoot 3 和 Spring AI 生态构建的企业级智能体应用

SpringBoot 3 Spring AI MCP 协议 ReAct

🛡️ 基于 Spring AI 的企业级防诈骗 Agent 平台

项目描述： 基于 SpringBoot3 + SpringAI + RAG + ToolCalling + MCP 的企业级法律反诈智能平台。支持高并发多轮对话、记忆持久化、RAG 领域知识库检索，并完全基于 ReAct 思考模式 赋予智能体规划决策能力。

🔥 面试核心技术亮点：

  • 大模型接入与 Agent 架构：基于 ReAct 模式构建具备自主规划能力的 AI 智能体，利用 Spring AI 统一封装通义、Ollama 等多模型接口，实现任务分解、自主决策与循环执行，最终可联动外部工具自主生成完整反诈要点 PDF 报告。
  • 对话记忆与精准理解：自主开发基于文件系统的 ChatMemory，结合 Kryo 序列化 高效持久化历史上下文；并实现 Re-Reading Advisor 接口引导模型复读解析用户诉求，大幅提升复杂法律条文处理的准确率。
  • RAG 与向量知识库构建：集成 QuestionAnswerAdvisor 核心组件，结合 EmbeddingModel 将密集文本转化为语义向量存入 PGVector 数据库，同时无缝对接阿里云百炼知识库，强化垂直领域问答精度。
  • 多源工具调用与 MCP 协议：利用自研注解机制扩展 AI 能力边界，封装网页搜索、本地文件操作等工具；通过本地 Stdio 模式创造性集成高德地图 MCP，赋能 AI 结合地理空间位置进行精准反诈提醒与危险预测。

LangChain Milvus 混合搜索 意图识别

🎯 SmartRecruit - 智能简历推荐与筛选系统

项目描述： 基于 LangChain 框架深度定制的智能招聘交付系统。无缝结合了向量分布式检索（Milvus）、精确全文搜索（Elasticsearch）与关系型存储（MongoDB），全自动化驱动简历结构化解析与混合精确推荐。

🔥 面试核心技术亮点：

  • 密集稀疏双向量编码 + 深度重排：基于前沿 BGE-M3 嵌入模型实现精细化的稠密与稀疏向量编码，并挂载 CrossEncoder 进行二次深度重排序，相较于传统单一向量检索，精准度提升 35%。
  • 大模型意图识别与参数抽取：独立设计大模型意图分析网关，自动将 HR 随意的自然语言招聘诉求进行语义重写与槽位抽取，全面支持 6 大类基础用户意图的精准卡口分类。
  • 简历结构化流水线 (Parent-Child Chunking)：构建完美支持 PDF/Docx 及基于图像大模型 OCR 识别的结构化抽取组件，通过父子块切分核心算法优化切片颗粒度，防止子块检索遗失完整的上下文边界。
  • 专业评测体系指标交付：使用生产级大模型评测标准框架 Ragas 对全链路检索策略进行压测调优，运用混合检索策略成功使系统 Recall@5（前五项召回率）达到 89%，整体端到端对话延迟完美收敛在 3~5 秒。

🤖 InsightScan 智扫通｜扫地机器人智能问答与报告生成 Agent 系统

项目描述： 专为扫地机器人量身定制的私有化大模型智能体系统。通过本地轻量大模型驱动，打通了“多源文档知识库问答（RAG）”与“外部业务数据库参数抽取生成报告”两条核心链路。

🔥 面试核心技术亮点：

  • 基于 ReAct 的多工具路由调度：利用 LangChain 封装 ReAct 思考看板，让 Agent 具备根据用户意图自主决策的能力。当遇到设备操作疑问时路由至本地 RAG 工具，当收到“分析特定月份使用情况”时则自动切换至报告生成流。
  • 多源数据融合 RAG 本地知识库：基于 ChromaDB 持久化向量库，支持 PDF、DOCX 硬件说明书及 CSV 格式的用户行为日志解析，使用 bge-m3 模型进行高性能本地 Embedding，提供高可用的设备知识检索问答。
  • 端到端报告生成流水线：实现大模型参数提取机制。Agent 自动捕获用户自然语言中的 User_ID 与 Month，触发 Pandas 自动检索底层业务数据中的多维度清洁轨迹和报错频率，最终由 Qwen3 渲染输出深度定制的使用分析报告。
  • 小模型工具调用容错增强（亮点）：针对本地轻量化模型 JSON 输出不稳定、易格式崩溃的问题，使用 Pydantic 协议硬约束 结合 自定义正则表达式防御解析网关，使小模型在离线私有化环境下的 Tool Calling 稳定性跃升。
  • 多触点交互交付与生产级评测：后端基于 Flask 搭建标准的 Web 服务接口，前端快速构建 Gradio/Streamlit 可视化客户端；并通过 ROUGE、BERTScore 以及 Faithfulness（忠实度）指标建立了一套完善的 RAG 幻觉量化压测框架。
